NativeOrchestrator

A central orchestrator for long-running sagas on the .NET Generic Host. It calls external systems, polls them until their work finishes, and compensates the steps that succeeded when a later one fails. There is no workflow engine: every saga is a database row with a due time, so nothing waits in memory.
